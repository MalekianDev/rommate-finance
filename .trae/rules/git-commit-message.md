Rules for commit messages:

- Use a short, descriptive title in the imperative past style (e.g. "- Added", "- Fixed", "- Removed", "- Refactored", "- Improved", "- Updated").
- Capitalize the first word.
- Do not end the title with a period.
- Keep the message concise (preferably under 72 characters).
- Describe the main change only.
- Examples:
  - Added handle_join_start
  - Added find method to BaseRepository
  - Improved room member loading
  - Fixed user registration bug
  - Refactored authentication service
  - Updated README.md if exists
